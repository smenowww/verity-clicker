# VERITY CLICKER — soft horror build

Обновлённая версия кликера с пользовательской музыкой и голосовыми звуками Verity.

## Что изменено

- Фоновая музыка: `audio/music.m4a`.
- Музыка автоматически повторяется по кругу.
- Музыка запускается после первого взаимодействия с игрой — это стандартное ограничение браузеров.
- На каждый клик по Verity случайно проигрывается один из 8 звуков `click_1.wav` — `click_8.wav`.
- Один и тот же голосовой звук не выбирается два раза подряд.
- При очень быстрых кликах одновременно звучат максимум 3 реплики, чтобы голоса не превращались в шум.
- 8 исходных реплик выровнены по громкости.
- Кнопка 🔊/🔇 управляет и музыкой, и репликами, и игровыми эффектами.
- При паузе YouTube Playables музыка также ставится на паузу.

## Визуальный стиль

Сделан мягкий хоррор-режим без скримеров:

- более тёмная сцена;
- лёгкая красноватая дымка;
- виньетка;
- едва заметное мерцание надписей;
- мягкая анимация Verity;
- внешний вид лица и освещение немного меняются при росте нестабильности;
- сильные глитчи остаются только для Glitch Rush.

## Запуск на компьютере

Самый простой вариант: открыть `index.html` двойным кликом.

Если в будущем установишь Node.js или Python, игру также можно запускать через локальный HTTP-сервер. Для обычной проверки текущей версии это не обязательно.

## Файлы

- `index.html` — интерфейс игры
- `styles.css` — оформление и хоррор-эффекты
- `game.js` — игровая логика и YouTube Playables API
- `audio/music.m4a` — фоновая музыка
- `audio/click_1.wav` ... `audio/click_8.wav` — голосовые звуки клика
